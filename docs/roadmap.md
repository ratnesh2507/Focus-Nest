# Roadmap

This document tracks the planned evolution of Focus Nest.

---

# v1.0 — MVP ✅

Initial local productivity application.

## Features

- Pomodoro timer
- Session notes
- Focus Mode
- Lofi music
- Zustand persistence
- Browser notifications

---

# v2.0 — Cloud & Analytics ✅

Full-stack SaaS foundation.

## Completed

- Google OAuth authentication
- Supabase integration
- Cloud session recording
- Dashboard analytics
- Study streak system
- Monthly heatmap calendar
- React Router architecture

---

# v2.1 — Productivity Analytics

## Planned

# Long-Term Vision

Focus Nest aims to become a modern productivity ecosystem focused on:

- deep work
- consistency
- calm design
- long-term learning habits

while maintaining a minimalist user experience.
